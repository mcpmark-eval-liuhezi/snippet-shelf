# Snippet Shelf

**a tiny, opinionated home for reusable code snippets**

Snippet Shelf keeps the code snippets you actually reuse in one tidy place — searchable, tagged, and easy to pull back out when you need them.

## What's here

- A README like this one introducing the project
- An issue tracker that holds the v0.1 roadmap and its feature issues
- A contributing guide (see `CONTRIBUTING.md`) for proposing changes

## Status

Very early — this is the kickoff scaffolding for v0.1. See the roadmap issue for what's planned next.
